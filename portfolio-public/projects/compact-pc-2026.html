Making everything fit

The parts list was only the beginning. I still had to fit the motherboard, graphics card, 280 mm radiator, power supply, tubing, and cables into the NZXT H2 Flow Mini-ITX case.

The open-panel view

I included the open-panel photos because they show the component layout and cable routing better than the finished front view. The build uses a modular SFX power supply and a 280 mm all-in-one cooler.

The complete build

The full configuration is listed below. This is a separate build from my first custom PC, with a different case, platform, and set of components.

Putting the system together

I selected the parts, assembled the computer, and worked through the full system layout. A Mini-ITX build puts the motherboard, graphics card, 280 mm cooler, power supply, storage, tubing, and cables into a tight space, so the component list only tells part of the job. The open-panel photos show how everything was arranged inside the NZXT case. The finished front view shows the same system closed up and running.
