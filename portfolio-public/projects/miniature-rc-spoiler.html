A tiny object changes the problem

The April 2021 post describes this as my smallest, most complex print at the time: a 1/32-scale RC-car spoiler, printed with a 0.2 mm nozzle and 0.12 mm layers.

Change the setup, not just the settings

It took several attempts to settle on an orientation. My preferred result at the time was a halved version printed without supports. The original photograph preserves the small pieces and trial layouts.

The next check belonged to the user

The caption ends by waiting for user feedback. That is where this project record stops; it does not supply a later fit or performance result.
